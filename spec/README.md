# spec

web（AI）と api（オーナー）の約束事。**ここに書かれたものが唯一の正**。

| ディレクトリ | 内容 | 状態 |
|---|---|---|
| `battle/` | クエストバトルのルールのゴールデンテスト | 計算ルール確定（v0.2）・ケースは追加中 |
| `openapi/openapi.yaml` | API の定義（OpenAPI 3.1）。エラーは RFC 9457 の形 ＋ `code` | 認証・`/me` の下書き（レビュー中） |
| `master/` | マスタデータ（キャラ・クエスト・天気・アイテム）。api が DB に投入して配信する（`docs/02` §10） | 初版（旧作から移行） |
| `tools/validate.py` | spec 全体の検証（スキーマ・相互参照）とマスタのバージョン計算 | — |

## 検証
```bash
pip install jsonschema
python3 spec/tools/validate.py
```

## 変更のルール
1. AI が下書きする（または変更を提案する）。
2. **オーナーがレビューして確定する。**
3. web と api は、spec が通るまで実装を直す。**実装に合わせて spec を書き換えない。**
4. spec が間違っていると思ったら、実装を変える前にオーナーに相談する。
