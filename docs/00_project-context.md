# K（ケイ）リメイク プロジェクトコンテキスト

> 状態: ドラフト v0.2（2026-09-25）。旧ソースを解析済み。
> 「確定」「推定」「未確認」を区別して書く。

## 1. プロジェクトの目的

| # | 目的 | 補足 |
|---|------|------|
| ① | K の完全リメイク | Web + iOS/Android（各アプリストア）のクロスプラットフォーム |
| ② | AI 駆動開発の練習 | **フロントエンドは AI が全部書く / バックエンドはオーナーだけが書く** |
| ③ | Kotlin の学習 | バックエンドは Kotlin + Spring Boot（必須） |

### 役割分担ルール（重要）
- `api/` 配下（バックエンド）: オーナーが書く。AI はコードを書かない。レビュー・解説・API 仕様の相談のみ。
- フロントエンド: AI が実装する。
- 両者の境界は **API 仕様（OpenAPI 等）** で定義する。

## 2. 旧作 K の情報（出典: appget 記事 2021-12-16）

### 確定情報
- 開発: FickleWolf（大阪府羽曳野市）/ 公式X: @FickleWolf_k
- リリース: 2021-12-16、iOS 15 以上、現在配信終了
- 旧エンジン: Unity
- ジャンル: カジュアル／ターン制コマンドバトル RPG、**1 対 1** の対戦形式
- コアシステム: **ターン式リターンバトル** — 任意のターンまで時間を戻せる「リターン」
- バトルコマンド: 攻撃 / 防御 / バフ / リターン / 必殺技
- 属性相性あり
- 必殺技の発動条件（全て満たす）: リターン済み / HP 半分未満 / 3 ターン目以降 / 最終ターンの 3 ターン以上前
- 倒したモンスターが仲間になる
- ガチャ、図鑑、アイテムによるキャラ強化
- オンライン対戦（ユーザー同士の戦略バトル）
- 手書き風モンスターイラスト、自作 BGM

### 記事での評価（リメイクで改善したい点の手がかり）
- 良: 独創的なビジュアル、時を戻して戦う革新的なコマンドバトル
- 課題: 未完成な箇所が散見 / オンラインのマッチング人口不足

## 3. 確認状況

### 解決済み（旧ソースから判明）
- [x] 最終ターン = クエストごとのターン上限（7〜36）。最終ターンに敵が必ず即死級の必殺技を使う
- [x] リターン = ターンと敵の行動ポインタだけ戻す（HP・バフは戻らない）。1 回まで。チェック（2 回）が必要
- [x] 敵の行動は固定パターンで決定論的（乱数はビリビリの 50% 判定だけ）
- [x] ダメージ計算式・ステータス（HP / ATK / DEF / SPD）・バフ（永続・加算）
- [x] 属性は 陽 > 音 > 月 > 陽 の 3 すくみ（×1.25 / ×0.75）
- [x] パーティは無し。1 体を選んで出撃
- [x] 進行 = メインクエスト初クリアで Lv+1、Lv に応じてクエスト解放。ストーリーは無し
- [x] 通貨はお札（ガチャ 5 枚）。課金 6 商品と報酬付き広告あり
- [x] 強化 = 属性別アイテム 12 種 + 被り + 日替わり天気
- [x] オンライン対戦「15thクノット」= 15 ターン事前編成 + リアルタイムでの割り込み（チェック / リターン / 必殺技）

## 4. 技術選定

| 領域 | 候補 | メモ |
|------|------|------|
| バックエンド | **Kotlin + Spring Boot 4 / MySQL 8.4**（確定） | `api/` にクリーンアーキテクチャ構成の雛形あり（パッケージ `com.ficklewolf.k`、起動クラス `KApplication`） |
| フロント（Web+iOS+Android） | **React + TypeScript（Vite）、ストア配信は Capacitor**（確定: D-2） | 構成の詳細は 02_requirements.md §9。iOS は Mac が無いのでクラウドでビルドする |
| バトルのルール | フロントとサーバで別々に実装し、ゴールデンテストで一致を保証（確定: D-1） | テストケースは `spec/battle/`（仮） |
| API 仕様 | OpenAPI（フロント/バックの契約） | バック=オーナー、フロント=AI の分担に必須 |

## 5. リポジトリ現状（2026-09-25）
```
K/
├── api/            Spring Boot マルチモジュール雛形（domain / application / infrastructure / presentation / bootstrap）
│                   パッケージ com.ficklewolf.k / 作者 FickleWolf
├── docs/           本ドキュメント・解析レポート・設計書
├── .gitignore      モノリポ共通の除外設定（legacy/unity など）
├── spec/           （予定）OpenAPI・ゴールデンテスト。web と api の約束事
├── legacy/
│   ├── unity/         旧 Unity プロジェクト（.gitignore 済み。署名鍵・GS2 認証情報を含む）
│   ├── data/          抽出したマスタデータ（JSON）
│   └── tools/         移行スクリプト（Python）
└── web/            フロントエンド（Vite + React + TS。AI が実装。pnpm の設定・lockfile もこの中）
```
- **モノリポ**（2026-09-25 git init）。git は K/ に 1 つ。各プロジェクトのツール（Gradle・pnpm）はそれぞれのフォルダの中で完結させ、直下には `.gitignore` 以外を置かない。
